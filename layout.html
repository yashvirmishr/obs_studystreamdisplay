OBS layout editor

Arrange your overlay

Drag the cards inside the 16:9 stage to design an arrangement, then save it as a profile. Each profile gets its own OBS browser-source link. Positions are percentages of the source, so they hold at any OBS size.

Control panel

Profiles

A profile stores the position, size and visibility of every card. Deleting always keeps at least one profile.

Scene defaults

Scene defaults apply when the OBS URL has no ?layout= parameter.

Selected card

Click a card on the stage to select it. Drag its green corner to resize.

OBS links

Copy a link into an OBS Browser source (1920 x 1080 recommended). The “Please wait” link hides the study dashboard but keeps every other card.

Stage - drag to arrange
Changes only reach the stream after Save layout. The overlay re-reads its profile automatically about once a second, so OBS sources pick saved changes up without a refresh.
