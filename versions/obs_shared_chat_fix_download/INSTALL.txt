PLEASE WAIT CHAT MATCHING PATCH
================================

This patch makes both OBS scenes use the exact same overlay.html implementation.

1. Extract this ZIP.
2. Copy overlay.html and wait.html into your existing study_status_overlay project folder, replacing those two files.
3. Do NOT replace study_state.json, server.py, control.html, or the YouTube extension.
4. In OBS, keep the Study Browser Source URL as:
   http://127.0.0.1:8765/overlay.html
5. Keep the Please Wait Browser Source URL as:
   http://127.0.0.1:8765/wait.html
6. Refresh both Browser Sources.

The wait.html page redirects to overlay.html?mode=wait. This hides the study dashboard and moves YouTube Now Playing to the top-left. The combined Twitch + Kick chat is the same single markup, CSS, iframe URL builder, size, position, and settings used by the Study scene.

No server restart is required. Keep the existing server running.
